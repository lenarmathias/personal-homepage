# Maciej Lenartowicz Personal Homepage

## Overview

This project is my personal homepage, containing my contact information, a list of known and to-learn technologies, and a portfolio of GitHub repositories. The portfolio projects are fetched via the GitHub API.

The site also offers a dynamic user experience with both light and dark modes, allowing visitors to tailor their viewing experience to their preferences. The selected theme is saved in local storage, ensuring a consistent experience each time the site is visited.

This project was originally built with Create React App and has since been migrated to Vite.

## Tools & Technologies

- **Vite**: Used as the development server and build tool.
- **Google Fonts**: A free online library of fonts that was used to enhance the application's typography and overall design.
- **Git/GitHub**: A version control system and online repository that was used to track changes to the application's code.
- **HTML**: The application's user interface is built using HTML, which allows for the creation of structured, well-formatted content.
- **CSS**: The application's styling is done using CSS, which allows for the creation of visually appealing and responsive designs.
- **JavaScript**: The application's logic is written in JavaScript, which enables dynamic and interactive functionality, such as real-time updates and user input validation.
- **React.js**: The application uses React.js, a JavaScript library for building interactive user interfaces with reusable components.
- **Styled Components**: A CSS-in-JS library used for styling React components.
- **Axios**: A JavaScript library used for making HTTP requests from the browser.
- **Redux**: A state management library used to manage the application's state.
- **React Redux**: The official React bindings for Redux, used to connect the Redux store with React components.
- **Redux Toolkit**: A set of utilities that simplifies Redux development and state management.
- **redux-saga**: A middleware library used to handle asynchronous actions and side effects in Redux.
- **react-icons**: A library providing a collection of customizable icons for React applications.

## Available Scripts

In the project directory, you can run:

### `npm run dev`

Starts the Vite development server and automatically opens the application in the browser.

### `npm run build`

Builds the application for production and outputs the files to the `dist` folder.

### `npm run lint`

Runs ESLint to check the project for code quality and potential errors.

### `npm run preview`

Starts a local server to preview the production build from the `dist` folder.
